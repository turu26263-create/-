# 研究の記録(2026-10-30)

データ:GitHub TheSnowGuru/Financial-Time-Series-Data-Features の forex/usdjpy/USDJPY_M5.csv
(UTC、2021-01-11〜2023-09-11、20万本。重複0・3日超えの穴0・高安の矛盾0を確かめた)
取り方:git clone --filter=blob:none --no-checkout --depth 1 → git checkout HEAD -- forex/usdjpy/USDJPY_M5.csv

決まり:2021〜2022 で探す。2023 は最後に1回だけ見る。スプレッド 0.5p と 1.0p の両方。

| 何 | 結果 |
|---|---|
| わがまま v0.1(A戻し+B押し目) | 全年マイナス。PF0.84(0.5p)、スプレッド0でもPF0.97=元から取れない |
| 時間ごとのくせ(scan1) | 東京7時台など2021〜22は強いが2023で逆。2022の円安の流れが混ざっている。使わない |
| 戻し(帯の±2〜3σ)324通り | 2021・2022 の両方プラスは0通り。スプレッドに負ける |
| 抜け(scan2・oos) | 両年プラスは抜けだけ。N24〜72・網2〜3ATR・利確3〜5ATR の広い台地で2023もほぼプラス |
| 採った形 | N36・網3ATR・利確4ATR・48本・UTC7〜17時:2021 +317p/2022 +1843p/2023 +473p、PF1.11(0.5p)。1.0pだと2021 −237p |

速さ:numba の研究台で 648通りが5秒(前の試験機は1通り2.4秒)。
弱いところ:1回あたり約1ピップの薄い取り。稼ぎの7割が2022の円安の年。2024〜2026は未確認(データが無い)。
