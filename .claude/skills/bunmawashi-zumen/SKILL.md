# ぶん回しエンジン 制作図面(2026-11-06)

## 0. 決まり(変えない)
- 回すのはエンジンの仕事。私が手で何通りも回して合計を並べて選ぶのは禁止(CLAUDE.md 最重要2)。
- ロープの編み方:決まりは1本ずつ。足したらその1本をローソクとたくちんの印で照らし、ミスを探す。全部照らすまで全期間の合計は見ない。
- 決まった形は、たくちんの「ご」が無いと変えない。部品を作るのと、形に入れるのは別。
- 遅行スパンは21本前。返事の頭は🔴🔴🔴。返事・たくちんが読む記録にはプログラムの名前を出さない。
- ループ禁止:作ったら、聞かずに関所→照らし→数字まで同じ返事でやる。聞くのは形を変える・お金・EAを書く、だけ。

## 2. データと時刻
- MT4 1時間足(サーバー時刻、2016/03〜2026/09)= 本番に近い。数字の正はこっち。
- HistData 1分足(EST、2015/01〜2025/04)= 足の中の高安の順番を見る時。MT4 = HistData + 7時間。
- 日足の区切り:サーバー0時 = EST17時(同じ)。4時間足の区切りは違う(HistData は EST0時から)。
- 合図は「その足が閉じた時刻」から使える。入り・降りは次の足の始値。0時の足はスプレッドが開くので、入り降りは1時へずらす(決まった形)。

## 3. 部品を足す順番(1本ずつ)
1. たくちんの言葉を【置き換え】で1行に書く(何の足の・何が・どこで)。
2. 部品を書く。列は名前で取る。買いと売りで数えの名前を分ける。合図には「わかった時刻」をつける(前から続いている状態は、わかった時刻が入りより前なら降りに使わない)。
3. 関所1:バグバグ修正機に通す(買い・売り・鏡・順番・二度回し・先読み・玉の中身)。×があれば成績を見る前に直す。
4. わざと壊した形を作り、修正機が×を出すか確かめる。出なければ修正機に型を足す。
5. 関所2:test_all を回し、前の数字(回帰)が変わっていないか。変わったら理由を1行で言えるまで進まない。新しい部品の照らしと期待の数字を test_all に足す。
6. ローソクで照らす:修正機の「ローソクで見る」玉と、違いが出た玉を、1本ずつ時刻・値段・9/21・川で歩いて確かめる。
7. ここで初めて成績(下の4.)。たくちんが「照らして」「ご」と言った時、または部品の良し悪しを言うのに要る時だけ。

## 4. 回し方(成績を出す時)
- 今の決まった形と、1つだけ変えた形を並べる(2行まで)。何通りも並べない。
- 期間:選ぶ年 22-24 / 確かめる年 16-21・25-26。全期間の合計だけで決めない。
- スプレッド 0.3p(0時は開く)。売りは鏡で確かめてから。
- 違いが出た玉の数・一番得した玉・一番損した玉・だまし(早く読んで外れた回数)を書く。
- 形を変える提案は、確かめる年で崩れないことを見てから。決めるのはたくちん。
