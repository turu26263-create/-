# 位置関係把握(たくちん 2026-11-05)

## たくちんの言葉【たくちん】
- 「9割れから、ドテン場所」
- 「5エントリのロウソクいちがわかってないから、負けるんじゃ、位置関係把握スキル」
- 「ぶん回し🈲したら データ取れんやろ」「スキルぶん回し🈲五かいめ 覚えろや」
- 「川無視 魚道無視や」「別の川に魚が行ってるのに追いかけてない」

## 言葉
- 川 = ボリ帯 ±1σ の内側(ローソクの流れ)。魚道 = ±1σ〜±2σ のあいだ。竿先 = ±2σ の外
- 9割れ = 時間足の終値が EMA9 をまたいで確定した足。ここがドテンの場所(持っている玉を降りて、逆に入る)
- 5エントリ = 9割れの後、5分足で入る所

## 1本ごとに書く表(5分足。入る候補の前後を全部)
| 項目 | 書くこと |
|---|---|
| 時刻 | 5分足の開始(日本時間と、データの時刻) |
| 始高安終・陰陽 | |
| 5分の 9・21 | 値、9>21 か、終値は9・21の上か下か、ひげが9に触れたか |
| 位置 | 終値が 竿先(+2σ外)/上の魚道/川の中/下の魚道/竿先(−2σ外)のどこか |
| 1時間 | 9割れの足の時刻、1時間の 9・21 と川のどこか |
| 4時間 | 9と21、川のどこか、200 の上か下か |
| 判定 | 入る/待つ/入らない と理由1行 |

## 決まり
1. ドテンの場所は 9割れ(何分足の9かは、たくちんの言葉で決める。決まっていなければ聞く)
2. 5エントリは、位置を書いてから決める。竿先(±2σ外)で追いかけて入らない
3. 【置き換え・未決】戻り売り/押し目買い:ひげが5分の9に触れて、終値が9の向き側へ戻って確定した次の足 — たくちんの印と1本ずつ合わせてから決まりにする
4. 1か所ずつ。合計・年ごと・形の並べ比べに広げない(ぶん回し🈲)。済んだら報告して「よし」「ご」待ち
5. 照らしていない所は「未照らし」と書く
