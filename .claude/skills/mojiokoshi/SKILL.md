# 文字起こし_標準装備(2026年11月14日)

状態:【黄】写真の文字起こし(OCR)は照らし済み。音声の道具は書いたが、モデルが作業場から取れず【未照らし】。

## 芯(どの道具でも同じ)
- 言った通りに書く。関西弁・言いよどみも勝手に標準語に直さない(【たくちん】の言葉は意味が変わる)。読みやすくした版が要る時は別に作る
- 聞き取れない・読めない所は作らない:`[聞き取れず 00:12:34]` `[読めず]` と書く
- 時刻 `[分:秒]` と話し手(わかる時)をつける。話し手が分からない時は「話し手A」
- 数字・名前・専門の言葉(例:ZVW30、60B24L、T+13けた)は最後にもう一度聞き直し・見直しする
- 終わったら「全部で何分・何行・聞き取れず何か所」を書く

## 長い録音の時
- 10分ごとに区切って起こし、つなぎ目の前後10秒を重ねて見る(言葉が切れない)
- 議事録にする時は:決まった事 / まだの事 / 誰が何をいつまで、を分けて書く(jikeiretsu-kaiwa の並べ方でもよい)

## 写真の文字起こしで気をつける(照らしで出た読み違い)
- `T` が `「` に、`:` の前後の数字が増える(10:23→169:23)、`0` が `6` に。数字は計算や意味で必ず確かめる
- 傾き・影・かすれに弱い。まっすぐ・明るく・近くで撮り直すのが一番効く
