# 解析スピードアップ(標準装備) 2026-10-30

## 1. 作業の前に台帳を引く(スキルホスト)
- 始める前に、Drive「スキルホスト_台帳.md」(ID 1w3TF_GVPpvsUDyX-tIx4lKXsZZh2vzTz)の「作業ごとの割り当て」を引く。「必ず使う」のスキルを順に読み込んでから手を付ける。
- 作業の種類が変わったら(EA作り→試験→報告など)、その都度引き直す。
- 使ったら台帳の「効きの記録」に日付と効きを書く。足りない所は学びの帳(ID 1GPKHLx4rIS4XvFmm20zZMagxG2WByg49)に書く。

## 2. 速くする道具を入れる(クラウドは毎回まっさら)
```
pip install -q numba pandas
```
- 入ったかは `python3 -c "import numba"` で確かめてから進む。

## 3. 研究台を使い回す(1本ずつ書き直さない)
- このスキルのフォルダにある `kenkyu_kousoku.py` を使う(元はリポジトリ `EA_5分足ひんぱん/kenkyu_kousoku.py`)。
- 入りの印(+1買い/−1売り/0なし)の並びを作って `sim(df, sig, 網の幅, 利確の幅, maxbars=本数, spread_pips=スプレッド)` に渡すだけ。網・利確・時間切れで1本ずつ決済して返す。足の中で網と利確の両方に届いたら網が先(損な方に数える)。
- 数字の組み合わせは、`itertools.product` で全部並べて回す。1回目だけ組み立てに約1秒かかる。2回目からは速い。
- 速さの試し:`python3 hayasa_tameshi.py`(作り物の5分足20万本)。
  - 【照らし済】2026-10-30 クラウドで 432通り 7.8秒(1通り 18ミリ秒。抜けの線を引く計算も含む)。前の試験機は1通り2.4秒。約130倍。
  - 別の会話の記録では648通り5秒(機械の違いで変わる)。

## 4. 合わせ込みを防ぐ(速いほど危ない)
- 速くなると何千通りも回せる。その分、たまたま当たった組み合わせを拾いやすくなる。必ず minadein-saiteki の決まりで回す。
  - 探す年と確かめる年を分ける(例:2021〜2022で探し、2023は最後に1回だけ)
  - 一番の1点ではなく、周りもプラスの「台地」を採る
  - スプレッドは2通り(0.5と1.0ピップ)で回す
- 研究台の成績はMT5の実測ではない。採った形は、MT5で回して突き合わせてから本物と言う(fx-entry-sync、ichihon-terashi-921)。

## 5. データが無い時はネットを探す
- クラウドからは、為替の置き場の多くが入口でふさがれている。GitHub は git で取れる。
  - 例:TheSnowGuru/Financial-Time-Series-Data-Features にドル円の1分〜日足(2021〜2023/9)
  - 取り方:`git clone --filter=blob:none --no-checkout --depth 1 <場所>` → `git checkout HEAD -- forex/usdjpy/USDJPY_M5.csv`(要る物だけ取る)
  - 取ったら、重複・3日を超える穴・高安の矛盾を数えてから使う
- Drive の道具は中身を会話に流すので、10MBを超える物は取れない。宝物ターンテーブルの kakiko_data(年ごと約2.5MB)と 円ドル(各3.5MB)は小さい単位で取るか、パソコン側でリポジトリの data/ に入れて押し上げてもらう。
- 2024〜2026 の足は、パソコンで `mt5_kakidashi.py` を流して書き出す。

## 6. 速さのコツ
- 線(移動平均・帯・高安)は、組み合わせの外で1回だけ計算して使い回す。
- pandas で1行ずつ回さない。並べたまま計算する(numpy)。1本ずつの決済だけを研究台に任せる。
- 大きいファイルの読み書きと長い計算は、分身に任せて会話の量を節約する(setsuyaku)。
