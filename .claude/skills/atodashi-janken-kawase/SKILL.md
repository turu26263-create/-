# 後出しじゃんけんで勝つ(たくちんの為替の考え方)

## 根っこ
- 未来は見えない。だから先に出さない(予想して先回りしない)。
- 為替が先に手を出す(走る)→ 確定した足でその手を見る → その方向に後からついていく。
- 頭と尻尾はくれてやる。真ん中の太い所(くじらの胴体)だけ取る。
- 判断の材料は「起きた事実」だけ。

## ゴンのじゃんけん(3拍子)= 最初の入口
1. 最初はグー(貯め)= レンジ。ボリンジャーバンドが縮み、遅行スパンがローソクに絡んでいる。手は出さず、力を貯めて待つ。
2. じゃんけん(構え)= バンドが開き始め、遅行スパンがローソクから抜けかける。構えるが、足が確定するまではまだ出さない。
3. ポン(放つ)= 遅行スパンのレンジ抜けの矢印。貯めの後、確定足で遅行スパンがローソクから抜けた所で、抜けた方向に出す。
- 出す手は自分で決めない。為替が決めた手を見てから出す。これが後出し。
- グーの間に手を出す(レンジで入る)のは反則負け。貯めの無い矢印(いきなりの抜け)もポンとは数えない。

## 遅行スパンのレンジ抜け矢印(ポンの印)の実装
- 遅行スパン = 今の終値を過去にずらして置いた線。ずらす本数は21(たくちん 2026-10-30「遅行スパン21や」)。パラメータにしておく。
- 比べるのは、確定足の終値 Close[1] と、その21本前のローソク(足番号1+21)の高値・安値。
- 絡んでいる(グー)= 遅行スパンがそのローソクの安値〜高値の間にある。
- 貯めの条件(数字は検証で決める):
  1. 直近N本のうちK本以上、遅行スパンがローソクに絡んでいた。
  2. その間、ボリンジャーバンドの幅が縮んでいた(幅が直近M本の中で狭い側)。
- 上の矢印(買い)= 貯めの後、Close[1] がその21本前のローソクの高値を上に抜けて確定し、一つ前の足(Close[2])ではまだ抜けていなかった。
- 下の矢印(売り)= その裏返し(安値を下に抜けた)。
- 矢印は新しい足が出た瞬間に1回だけ判定し、1つの貯めにつきポンは1回。
- チャートに矢印を描いて、たくちんの矢印(手で入る所)と重なるか先に照らす。ずれたら定義の方を直す。

## キルアの鳴神(ナルカミ)= 押し目(戻り)で足す一撃
- ポンの後、走っている流れの中で一度戻ってきた所(上向きなら押し目、下向きなら戻り)に、雷を落とすように一発足す。
- 打つ条件:
  1. 上の足の流れが生きている(遅行スパンがローソクから離れたまま)。
  2. 押し目の帯まで戻ってきた(どの帯かは検証で決める。手の鏡打ちでは±2σで待つ)。
  3. 戻った後、元の方向への足が確定した。ここで初めて打つ(帯に触れただけでは打たない。ここも後出し)。
- 打たない時: 戻りで遅行スパンがローソクに絡んだ、バンドが縮んだ = 押し目ではなく次のグー。鳴神は打たず、降りる準備。
- 鳴神は25%×4の残りの玉を足す場所。1回の押し目で打つのは1発。上限を決めて無制限に足さない。
- 足した玉にも必ず出口を付ける。

## ロジックの決まり
1. 判断は確定足だけ。確定前の足やひげでは入らない・切らない。
   - MQLでは判断値は必ず1本前(shift=1)。新しい足が出た瞬間に1回だけ判定。
2. 入口は「走り出した後」に出る印にする(ポンの矢印、鳴神の印)。
3. レンジ(グー)では何もしない。ドテンしない。
4. 上の足が走っている方向にだけ、下の足で乗る(日足→4時間→1時間→5分)。
5. 分けて入る(25%×4)。1発目はポンの斥候。残りは鳴神で足す。
6. 損切りは揺れの外。確定足で判断。
7. 出口も「走りが止まった事実」で決める。
   - 遅行スパンがまた絡む、バンドが縮む=次のグーが始まった。降りる準備。利確は自動で±3.5σ。

## 作る手順
1. 過去チャートをローソク1本ずつ見て、グー・じゃんけん・ポン(矢印)・鳴神を印で書く(かきこチャート)。取れる最大値を先に出す。
2. 印をルールの言葉に直す。
3. EAに書く。判断値はすべてshift=1以上。未来の足を見ていないか全行照らす。コンパイルとチャートへの貼り付けまでやる。
4. 3年分で確かめる。この足でしか勝てないなら合わせ込みを疑う(隣の足・足の区切りずらし・別の3年)。
5. 温故知新の書と呪文の書を引いてから数字を評価する。

## 照らしの問い
- ポンや鳴神が為替の手より「前」に出ていないか(先出しになっていないか)
- 矢印の前に貯め(絡みとバンドの縮み)があったか
- 確定前の値を使っていないか
- グー(レンジ)で入っていないか。押し目と次のグーを取り違えていないか
- 上の足と逆を向いていないか
- 足し玉に上限と出口があるか
