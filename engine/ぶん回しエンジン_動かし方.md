# ぶん回しエンジン 動かし方(コンピュータ)2026-11-19

どのパソコン・クラウドでも、この順でエンジン(engine/nyu)が動く。部品は同じ皿の bunmawashi_engine_nyu.zip(リポジトリでは engine/nyu)。

## 1. コンピュータの用意
- Python 3.11 以上(照らし済み:3.13.18)
- 入れる物:`pip install pandas numpy numba matplotlib`(照らし済みの版:pandas 3.0.5・numpy 2.5.3・numba 0.68.1・matplotlib 3.11.2)
- Windows でも Linux でも同じ。numba は最初の1回だけ組み立てに数十秒かかる(2回目から速い)
- 速さ:決まった形を10年分1回まわして約5秒(クラウドの1台)。部品を並べて回す時は CPU の数だけ同時(turbo.py)

## 2. データ
- MT4 1時間足(本番の照らし):Drive の USDJPY60.csv(ID 1TkE0f6bu-QXOU-5BJT_Jnr14of6vCjDv)を、好きなフォルダ(例 data/mt4/)に置く。中身は MT4 の書き出しの形(日付,時刻,始,高,安,終,量)・サーバー時刻・2016/03〜2026/09
- 今日までつなぐ時:Yahoo の1時間足(JPY=X)は MT4 サーバー時刻より夏3時間・冬2時間おそい(ずれの中央値0.5p)。11-19 は data/mt4_now/ に 2026/11/19 14時までつないで照らした
- 1分足(test_all.py の照らしに要る):GitHub yukkiya/usd-jpy-data の zip を解いたもの(HistData・2015/1〜2025/4)

## 3. よく使う回し方(engine/nyu で)
| したい事 | 打つ物 | 出る物 |
|---|---|---|
| 決まった形の成績(0.01と カウンター反撃7段) | `python3 kenkyu/nanpin7.py data/mt4` | 最後の資金・落ち込み・年ごと・段ごとの玉数 |
| 歩いて検証(エンジンの部品を使わず作り直して1玉ずつあわせる) | `python3 kenkyu/aruki_zenbu.py data/mt4` | 部品ごとの一致数・降りた理由・5つの局面 |
| MT4 とあわせる表 | `python3 kenkyu/ea_v4_awase_csv.py` | ea/Kujira3_v4_研究台の玉_MT4あわせ用.csv |
| かきこチャート | `python3 kakiko_make.py data/mt4 出す先.html` | 1枚の html(出し直しは https://claude.ai/artifact/3Xp367cAgeuUXQ4AExy3Q8 だけ) |
| 勝ち負けの材料 | `python3 kenkyu/zairyo.py` | 材料ごとの勝率・平均p |
| 大山の画像 | `python3 kenkyu/oyama_gazou.py 2024-07-16 2024-10-01 8` | 1時間足・4時間足の png |
| 最適化(カウンター反撃×無限リーチ) | `python3 kenkyu/saiteki_nanpin_mugen.py` | 発数・掛ける部品・資金ごとの表 |
| 全部の照らし | `python3 test_all.py 1分足の置き場 data/mt4` | 回帰・暴走・部品の照らし(1分足が要る) |
- kenkyu のスクリプトの中のデータの置き場は /home/user/data/mt4 と書いてある所がある。別のパソコンでは自分の置き場に書き換えるか、同じ置き場を作る

## 4. 決まった形(settei_kimari.json)
- クジラ買い売り(週足逆は別の枠で上限なし)・ドテン買い・鯛(日足の並び・NY外し)・日足の押し目巡航・しあわせセット。ロットはカウンター反撃7段
- 967玉・0.01固定で最後 521,624円・落ち込み11.7%/7段 5,674,709円・92.9%(資金10.2万)(11-24 2026年のデータの穴をうめた後)
- 決まりを変える時はたくちんの「ご」。変えたら settei_kimari.json と EA(4_武器の皿)と かきこチャートを同じにする

## 5. 守る事(ぶん回しエンジン制作図面・バグバグ修正機の決まり)
- 判断は確定足(1本前)、入りは次の足の始値。上の足の線は「閉じた時刻」で貼る(on())
- 足の中は 網 → 利確 → 合図の降り の順(損な方を先に見る)
- 変えたら歩いて検証(aruki_zenbu.py)で全部一致を確かめてから
- 制作図面・修正機の正本:2_スキルの皿「ぶん回しエンジン制作図面_標準装備_20261110.md」「バグバグ修正機_標準装備_20261110.md」
