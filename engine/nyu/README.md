# ニューぶん回しエンジン(engine/nyu/)— 2026-11-06 たくちん「eaあと ニューぶん回しエンジンつくるんがさき」

## 中身
| ファイル | 役目 |
|---|---|
| nyu.py | 土台。データ読み(HistData・MT4 書き出し)/足と線のしまい場所 Market(EMA9・21・200、±1・2σ、遅行21本前、21の角度、9割れ、921)/上の足を「閉じた時刻」で下の足に貼る on()/1玉ずつの売買 simulate()(numba。最大何発でも、芯と足しで降りを分ける、網を上げるだけ)/成績 report()(選ぶ年・確かめる年・含み損込みDD・降りの理由カウンター)/大山ひと山 hitoyama()/暴走チェック bousou()/ぶん回し grid()・台地 daichi() |
| tai_parts.py | 鯛の刺身とクジラの部品(縄1〜8、降り=9割れ・219・終値9)。run_tai() で1回まわす |
| kaiki_check.py | 回帰の照らし:これまでの結果がそのまま出るか |
| bousou_check.py | 暴走チェック:データを途中で切って前の戦が変わらないか・玉の上限・持ったまま |
| run_grid.py | ぶん回しの例(鯛・クジラ 192通り。スプレッド 0.5p/1.0p、選ぶ年 22-24・確かめる年 15-21/25、台地) |

## 照らし済み(11-06)
- 回帰:① 4時間版の鯛 買い 1,969戦 +3,910.8p ② 売り 1,820戦 +683.4p ③ 日足版の鯛 買い 265戦 +3,040.5p ④ 日足クジラ20発 284玉 +7,942.2p ⑤ 大山ひと山5発 5玉 +1,936.7p → 5つとも前のエンジンと同じ
- 途中で見つけて直したミス:降りの真偽を列の順番で取っていて、時刻の列を「いつも真」と読んでいた(回帰の照らしで見つけた)
- 暴走:3か所(2017/06・2020/03・2023/01)で切っても前の戦は同じ(先読みなし)。同時に持つ玉は上限以下
- 速さ:4時間版の鯛(5分足 75万本)1回 1.1秒。192通り(含み損込みDD つき)32秒

## 使い方
```
pip install -q numba pandas
python3 engine/nyu/kaiki_check.py <HistData 1分足の置き場> <MT4 1時間足の置き場>
python3 engine/nyu/run_grid.py <HistData 1分足の置き場> <書き出し先>
```
- データ:HistData 1分足 2015/1〜2025/4(GitHub yukkiya/usd-jpy-data の zip を解いた csv)/MT4 1時間足 USDJPY60.csv(Drive、2016/03〜2026/09)
- 研究台の数字。MT4/MT5 の実測ではない
