# Kujira3_v2.mq4(今の決まった形を MT4 に)2026-11-12

たくちん「mt4で回して」。研究台の今の決まった形(11-12)を、決まりを変えずに MT4 の EA にした物。
Kujira3_v1.mq5(MT5)の中身を MT4 に写し、しあわせセット(レンジの箱)を足した。

## 中身
- クジラの刺身(売り買い・最大5発)/ドテン買い/鯛の刺身(買いだけ)/日足の押し目巡航(売り買い・最大5玉):v1.mq5 と同じ
- しあわせセット(レンジの箱):日足の遅行スパン(終値と21本前の終値の上下)が直近30日で3回以上入れ替わる間がレンジ。前の日足の −2σ に値が届いたら4単位買う(刈る3・ため1、1単位0.01ロット)。売りは +2σ で4単位、ただし週足の9が21の下(219)の間だけ。日足200の上下1σの中・箱の外・0時・GW では入らない。刈るは反対の ±2σ、ためは ±3.5σ で利確。入った後に閉じた日足の終値が、入った時の箱(レンジに入ってからの高値・安値)の外なら全部降りる(0時は1時へ)。前のセットの刈るが残っている間は次のセットなし。ためは5つまで
- 休み:GW 4/29〜5/6 は新しく入らない。0時(サーバー)の足では入り・合図の降りをしない

## テスターの設定
- 銘柄 USDJPY・時間足 H1(H1 のチャートで動く)
- モデル:「全ティック」(しあわせセットは足の途中で値が線に届いた所で入るので、始値だけのモデルでは入りがずれる)
- 期間 2016.03〜2026.09・入金 102,000円・レバレッジ 2000
- 日足・週足・4時間足のデータもテスターに読み込まれていること(履歴センターで USDJPY の D1・W1・H4 を落としておく)

## 研究台と照らす
- 研究台の1玉ずつの表:ea/Kujira3_v2_研究台の玉_MT4あわせ用.csv(1,038玉 +37,325p。サーバー時刻。部品・入り・降り・pips・降りた訳)
- EA のログ:MT4 の tester/files の Kujira3v2_log.csv(入り・降り・スプレッド・見送り・しあわせの日足の値)
- テスターの「結果」タブの取引一覧(入りの時刻・値段)を送ってもらえれば、1玉ずつ照らす

- 2016/03 から(EA と同じ始まり):1,038玉 +37,325p・最後の資金 475,251円・落ち込み率 29.9%

## 研究台と違う所(分かっている物)
- スプレッド:研究台 0.3p 決め打ち。MT4 は業者の本物。入る直前に 5p より広ければ入らない(EA だけの守り)
- しあわせの入り:研究台は1時間足の安値が線に届いたら線の値で入る。EA はティックで Bid が線に届いた時の Ask で入る
- しあわせの箱割れ:研究台は「日足が閉じた時に持っていた玉」だけ見る。EA は「入った後に閉じた日足」で見るので、日足の最後の1時間(23時)に入った玉も、その日の終値で箱割れを見る(研究台より早く降りることがある。まれ)
- 週足:研究台は月曜0時からの7日足。MT4 の W1 は日曜から。日曜に足が無い業者なら同じ
- 日足・4時間足の区切りは業者のサーバー時刻。研究台の1時間足データ(MT4 USDJPY60.csv)と同じ業者なら同じ
