# Kujira3_v1.mq5(決まった形3を MT5 に)2026-11-09

たくちん「mt5でやって」。研究台(ぶん回しエンジン)の決まった形3を、決まりを変えずに MT5 の EA に写した物。

## 中身(決まった形3)
- 売り買い:日足の終値が青(9)の上(売りは下)・4時間の終値が赤(21)の上(下)の許しの中で、1時間の921(売りは219)+川の外(±1σ)+遅行スパン(21本前の高値の上)、または許しが出た瞬間(日足9の上に3本続いてから)。日足21の向き(3本前と比べる)が同じ時だけ。1時間 ±2σ の外(竿先)では入らない。同じ向き最大5発、1発0.01ロット
- 降り:日足の219(売りは921)が、入った後に閉じた日足で出たら全部。4時間 ±3.5σ で利確(1本前の4時間足が閉じた時の線)。TS 550p
- ドテン買い:売りが利確したら構えて、1時間の921が出た次の足で買い1玉。降りは4時間の新しく出た219と TS 550p
- 鯛の刺身(買いだけ・11-09「ご」):買いと同じ入りで1玉、4時間の9割れ(入った後に閉じた4時間足)で降り、TS 550p、利確なし
- 休み:GW 4/29〜5/6 は新しく入らない(持っている玉はそのまま。11-10 サンタ・寝正月はやめた)
- 0時(サーバー)の足では入り・降りしない。次の1時の足でやる

## テスターの設定
- 銘柄 USDJPY・時間足 H1(EA は H1 の足で動く。チャートの時間足は H1 にする)
- モデル:「1分足OHLC」か「全ティック」。期間 2016.03〜2026.09(研究台と同じ)
- 口座は**両建て(ヘッジ)口座**。ネッティング口座では動かずに止まる(売りとドテン買いを同時に持つため)
- 入金 102,000円・レバレッジ 2000

## 研究台と照らす
- 研究台の1玉ずつの表:ea/Kujira3_研究台の玉_MT5あわせ用.csv(596玉 +13,130p、サーバー時刻。鯛の刺身入り・休みはGWだけ)
- EA のログ:MT5 の Files フォルダ(テスターは Tester の中)の Kujira3_log.csv(入り・降り・約定・スプレッド・見送り)
- テスターの「結果」タブの取引一覧(入りの時刻・値段)を送ってもらえれば、1玉ずつ同じ足・同じ値段か照らす

## 研究台と違う所(分かっている物)
- 研究台のスプレッドは 0.3p 決め打ち。MT5 は業者の本物のスプレッド
- 研究台の利確・網は足の高安で判定。MT5 は本物のティック(買いは Bid、売りは Ask)
- EA だけにある守り:入る直前のスプレッドが 5p より広ければ入らない
- 日足・4時間足の区切りは業者のサーバー時刻。研究台の 1時間足データ(MT4 USDJPY60.csv)と同じ業者なら同じ区切り

## EA の写しの照らし(11-09)
- EA の手順を1時間足1本ずつそのまま Python でなぞった写し(engine/nyu/ea_utsushi.py)で、研究台の382玉と比べた → **2016/10/06 以降の玉が全部、入り・降り・損益まで同じ**(GWだけ休む形でも 596玉 全部同じ)
- 写しだけに出る30玉は 2016/03〜10 の物。研究台は日足21の角度に150日分の足が要るので、この間は入っていない(EA は入る)。テスターの結果と研究台を照らす時は 2016/10/06 以降で比べる
- 照らしで見つけて直した EA のミス:週末をまたぐ所で、合図の足が閉じた時刻ではなく新しい足の始まりの時刻で日足・4時間足を見ていた/「その時刻に閉じている足」の探し方が週末の穴で1本ずれる
