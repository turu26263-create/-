# たくちんのスキルパック(2026-11-14)

中身:4つのスキル。1つずつ別の zip です(Claude の画面では、zip を1つずつ入れます)。
- jikeiretsu-kaiwa.zip … 時系列会話(前の続きから進める・LINEやチャットの記録を時刻の順に並べる)
- denpyo-shori.zip … 伝票処理(レシート・請求書・領収書を読んで、計算で突き合わせる)
- mojiokoshi.zip … 文字起こし(音声・写真・紙を文字に。作らない・そのまま書く)
- tashite-dousakakunin.zip … アプリに足して動作確認

## 別の Claude に入れる
1. claude.ai を開く → 左下の名前 → 設定 → 機能(Capabilities)→ スキル
2. 「スキルをアップロード」で zip を1つ選ぶ(このパックの zip ではなく、中の4つの zip を1つずつ)
3. 4回くり返す。入ったらスキルの一覧で4つがオンか確かめる
※ 画面の名前は版で変わることがあります。スキルの欄が無い時は、その Claude の契約・設定でスキルが使えるかを先に確かめてください。

## Claude Code(パソコン・クラウド)に入れる
- zip を解いて、フォルダごと `.claude/skills/` に置く(リポジトリ turu26263-create/- には入れてあります)
