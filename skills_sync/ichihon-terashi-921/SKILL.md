# 921・219・5分足エントリーの一本照らし と 現実ローソクあわせ(最重要)

- 219 = 9が21を下抜けた所(売りの候補)

- 川 = ローソクの流れ(ボリンジャーバンド1σで見ても同じ)

## 絶対の決まり
1. ぶん回し禁止。合計の数字を見て決まりをいじらない(くびぽろっ)。
2. 先にたくちんの手の印(入る所)をもらう。無い時はかきこチャートで1本ずつ書いてから比べる。
3. 921・219・5分足エントリーは**1か所も飛ばさず**、その足と前後の足を1本ずつ見る。
4. 遅行スパンと矢印も必ず一緒に照らす。線の「描いてある位置(過去)」と「判断した足(今の確定足)」を取り違えない。
5. **書いたコードは必ず現実ローソクとあわす。** 手元で作った計算と、MT4で実際に動かしたEA・インジケーターの記録(矢印の時刻・入った時刻と値段)が、同じ足・同じ値段になるかを1件ずつ合わせる。合わない所が1つでもあれば「合っていない」と報告し、原因を書く。
6. 判断は確定足(shift=1以上)。描き直す矢印は失格。
7. 照らしていない所・あわせていない所は「未照らし」「未あわせ」と書く。嘘の完了報告をしない。
8. 返答は全部日本語。

## 手順
1. かきこチャートに921・219・5分足エントリーの全候補を印で出す。
2. 1か所ずつ上の表を埋める。前後数本も見て、レンジの中の交差か、抜けたあとの交差かを書く。
3. EAを書いたらコンパイルしてチャートに貼り、書き出された記録を手元の計算と現実ローソクに1件ずつあわす。
4. ×と?だけ集め、どの決まりが原因かを言葉で書く(数字は動かさない)。
5. 直し方の案はたくちんの「ご」が出てから当てる。直したら同じ所をまた1本ずつ照らし、あわす。
6. 照らしとあわせが全部済んでから、3年分で確かめる(最後の照らし)。
